# Nocturne Lab · 暗夜实验室

一个可以许愿的交互式星空。纯 Canvas + WebAudio，零依赖，单文件（`index.html`），双击即可运行。

**在线体验 → http://nocturne.xxz的试验场.xyz**（部署于阿里云杭州 ECS + nginx，域名解析在 Cloudflare）

## 玩法

- **移动鼠标 / 手指拖动** —— 三层视差星野随目光流转，天球缓缓漂移
- **悬停星辰（触屏长按）** —— 高亮整个星座，浮现中西方星名与传说
- **点击星辰** —— 触发超新星爆发，按星等奏出五声音阶（C 宫调），并在天上留下一颗金色许愿星
- **许愿成星座** —— 每 7 颗许愿星自动连成一座只属于你自己的星座，`localStorage` 持久化，明天打开还在
- **右下角 ✦ 流星雨** —— 一键召唤 8 秒流星雨
- **右下角 ♪** —— 开启环境音：Cmaj9 和弦垫 + 星点拨弦

## 技术要点

- **高分屏不糊**：渲染倍率 = `devicePixelRatio × visualViewport.scale`， pinch 缩放时重建后备存储；锐利星核保证放大后光点清晰
- **性能**：光晕按颜色预渲染为精灵图集（消灭每帧数十个径向渐变）；银河光带缓存在离屏 canvas、每帧仅一次 `drawImage`；页面后台自动挂起音频
- **统一输入**：Pointer Events 覆盖鼠标/触摸/触控笔；触摸长按 480ms 固定星座提示
- 虚拟天球坐标系（1000×800）→ 屏幕投影，12 组天体分 14 区排布互不重叠
- WebAudio 全程序生成音频：双振荡器失谐和弦垫 + LFO 呼吸 + 指数包络拨弦
- `localStorage` 读写全 try/catch，隐私模式下降级为不保存
