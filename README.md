# Nocturne Lab · 暗夜实验室

一个可以许愿的交互式星空。纯 Canvas + WebAudio，零依赖，单文件（`index.html`），双击即可运行。

## 玩法

- **移动鼠标** —— 三层视差星野随目光流转，天球缓缓漂移
- **悬停星辰** —— 高亮整个星座，浮现中西方星名与传说
- **点击星辰** —— 触发超新星爆发，并按星等奏出五声音阶（C 宫调）
- **右下角 ♪** —— 开启环境音：Cmaj9 和弦垫 + 星点拨弦
- **许愿里程碑** —— 7 愿「七曜同辉」，20 愿触发**流星雨**（持续 9 秒）

## 天上的五座星座

| 星座 | 看点 |
|---|---|
| 大熊座 · 北斗七星 | 天枢至摇光，斗柄辨四季 |
| 仙后座 | 绕着北极星旋转的 W |
| 天琴座 | 织女星与俄耳甫斯的七弦琴 |
| 天鹅座 | 「天津」—— 天河的渡口 |
| 猎户座 | 腰带三星，中国人的「福禄寿」 |

## 技术要点

- 虚拟天球坐标系（1000×620）→ 屏幕投影，五区排布保证星座互不重叠
- 背景 420 颗恒星三层视差 + 独立闪变相位
- 流星粒子拖尾（线性渐变），许愿 20 次进入流星雨模式
- WebAudio 全程序生成音频：双振荡器失谐和弦垫 + LFO 呼吸 + 指数包络拨弦
- DPR 感知渲染，高分屏不糊；`devicePixelRatio` 上限 2 控制性能
